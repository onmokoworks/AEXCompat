# Blender multi-parameter AEX bake on macOS (#1662)

In an AEXCompat compositor descriptor node, choose **Render AEX (macOS)**, set the plug-in path relative to `AEXCOMPAT_PLUGIN_ROOT`, and refresh parameters. Select a name in the available list and click **Add/update selected parameter**. Repeat for up to 16 distinct scalar slots, edit their integer or decimal values in the selected list, then bake. **Remove selected override** removes one row. Changing the plug-in source or refreshing clears the selected list. A node without selected names retains the previous single-slot control and default slot 0 behavior.

The wrapper validates the list, obtains one complete AEX description, resolves each distinct enabled and visible scalar slot, and submits the resulting parameter records to one existing headless fixture render. Unknown, repeated, hidden, disabled, non-scalar, non-finite, and out-of-range values fail before frame rendering. The response records the description and plug-in identity for each applied slot; the addon requires all records to share one description identity. Changed AEX bytes are recorded and warned about after a valid bake, without becoming a launch hash gate. Blender keeps chosen values as integers or decimal text to avoid its float-property rounding. An incomplete decimal edit can be corrected in the node UI; only Bake reports the invalid value. Identity transport ignores the AEX selection.

Blender 4.5.8 LTS smoke used license-free `OLMBlur.aex` (SHA-256 `f0611785e7b14ac4fcfc75f23b8862beb4539eee52d25d472556849535e96e5b`) and a 32×32 checker input. The default output SHA-256 was `b145d0d1a886bbe8a9801771424ad81801e86e8356ed9fffb90ce54ba5ffade0`. Blur Amount (slot 1) at 20 alone gave `8092afcf8b1974fba931fc8347ecebd5751731949fc01ad47ebdcd7d7f61360d`; Number of Repeat (slot 3) at 5 alone gave `baa607b718c9c7d2b094d043326d0b1f2a2f9888422326e26f639cac2b1aefc6`. Both together gave `13ad374624ea8e15c4d3c5fb015c45cac77ca8013c78e442d46e39a2a773c9e6`, different from all three other images, with 2,048 changed bytes versus the default. The native compositor produced a PNG, and a saved `.blend` reload preserved both values and all packed images. A malformed response with mixed description identities or boolean slot/value was rejected. After Effects was not started. The local AEX, `.blend`, PNG, and smoke JSON are not committed.

Run `tools/blender_aexcompat_multi_parameter_smoke.py` under Blender with the Release harness and guest worker, setting the same environment variables as `docs/BLENDER_AEX_SCALAR_BAKE_2026-09-30.md`. The custom Python node remains a descriptor: Bake writes a packed Image into Blender's native compositor graph; the node itself is not a direct compositor executor.
